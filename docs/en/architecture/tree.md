# Directory structure — the fully annotated tree

> English mirror of [docs/architecture/tree.md](../../architecture/tree.md) — the Chinese original is the canonical source; this plane is asserted at file-existence level by the docs-ssot en-parity battery.

> This document is the deep-dive version of the README's "Directory structure" section (migrated verbatim out of the README during the T13.1 layered refactor).
> For the quick version (three-level tree + scale facts) see [README](../../../README.en.md#directory-structure).

```
nix-config/
├── flake.nix               # entry layer: input declarations + a one-line delegation (outputs handed wholesale to lib/shared/faces.nix, R31)
├── shared.nix              # policy layer (generated by just shared-generate — hand-editing usernames is forbidden)
│
├── lib/
│   └── shared/
│       ├── default.nix     # shared loader: two-stage initialization (scfpath overridable, multi-machine support)
│       ├── targets.nix     # target factory (production side): hosts/ inventory → caps classification → emitters (nixos /
│       │                   #   darwin / standalone-HM — the three closure classes + the colmena deployment face + the two
│       │                   #   toplevel projection faces [hostToplevels / darwinToplevels, migrated from flake.nix in R31];
│       │                   #   Law G naming guard: the legacy alias <user>-<platform> never shadows a real host directory)
│       ├── faces.nix       # link layer (linker, R31): assembles each production side's output onto the flake
│       │                   #   protocol's output names (checks five-gate aggregation / module-docs factory invocation /
│       │                   #   pdsh built once / tests imported once / exports aggregation) — flake.nix is down to registration + the one-line delegation
│       ├── docs.nix        # docs factory (production side): export/ modules → optionsDoc markdown (side-channel emitter)
│       ├── lang/           # stage one · the language front end: types/enums/schema/validation (no pkgs)
│       │   ├── default.nix # stage-one aggregation: const + schema + enum + fn + tools + validate
│       │   ├── enum.nix    # enums and the platform capability table: arch / platform(caps) / portal / wm / dm /
│       │   │               #   sound / shell / drive-group / editor / editor-set /
│       │   │               #   terminal-set / browser-set / app-set / service-profile /
│       │   │               #   version / pointer-cursor / role (17 enum tables;
│       │   │               #   role carries the Law F role-policy-keys whitelist)
│       │   ├── schema.nix  # layered structural validation: user / git / rbw / time / i18n / secrets /
│       │   │               #   nixpkgs / shared (the 18-key full contract, loader-side) /
│       │   │               #   fleet (the 16-key fleet-layer contract, deliberately class-less)
│       │   ├── fn.nix      # pure utility functions: homeDir · sopsBase/sopsFile/sopsRuntimePath ·
│       │   │               #   pkgsFingerprint · sameSource (the eval-time dual-source guard)
│       │   ├── const.nix   # constants: secrets paths · permission modes(0400/0440/0600) · XDG directory names
│       │   ├── tools.nix   # external tool-repo registration: nix-types / orc-raw / pdshell-raw (short-path access)
│       │   └── validate.nix# Option/Result-typed secret path validation (eval-time declared-but-not-provided)
│       └── runtime/
│           └── default.nix # stage two · IR synthesis: caps/pkgs/upkgs/i18nScope/services/appCategories/...
│
├── platform/               # platform distribution layer (host-dispatch: directory grammar v4 — platform-first, domains explicit)
│   ├── nixos/              # NixOS dual-live gates: system/ = the system domain (system/default.nix = the system gate:
│   │                       #   core/dm/wm registration + hosts facts); home/ = the user domain
│   │                       #   (home/default.nix = the home gate — the gate IS the HM payload; the arch axis
│   │                       #   is retired: all arches flow through the same pipeline, arch differences absorbed at
│   │                       #   the nixpkgs layer by the emitter's system argument / per-host pkgs; the policy of
│   │                       #   second-level switching / independent rollback); system/{core,drive,exp,sec,srv} · dm/ · wm/
│   ├── linux/              # generic Linux: home/ = the only live gate — the gate IS the payload (standalone HM +
│   │                       #   nixGL(mesa) + genericLinux; having no system/ directory is itself the declaration of
│   │                       #   a system-less form — the entire platform directory holds only home/)
│   ├── darwin/             # macOS(nix-darwin): system/ = the only live gate (T5.8 single-gate folding:
│   │                       #   hm.darwinModule + hosts facts + the home-manager.users mount
│   │                       #   = import ../home in one — the system gate's cross-domain reference keeps the path
│   │                       #   visible); system/nix/ = the nix settings module (the fleet-cache pull side,
│   │                       #   shared.const consumed by value — the same identity, single-sourced with the nixos
│   │                       #   customs); home/ = the user-domain gate (module-mode mounting, not an independent gate)
│   ├── wsl/                # WSL2: home/ = the only live gate (standalone HM + nixGL +
│   │                       #   genericLinux + systemd; no system/ directory; the WSL userspace
│   │                       #   interop is provided per caps.wsl by the shared tree's home/core/base/wsl.nix,
│   │                       #   T7.1)
│   └── nixos-wsl/          # NixOS-WSL, the fifth form (T7.1): system/ = a thin gate —
│                           #   ../../nixos/system reuse + the NixOS-WSL interpreter; home/ =
│                           #   a thin gate (imports = [ ../../nixos/home ] reuses the nixos
│                           #   user-domain gate; the gate is the form definition)
│
├── home/                   # user layer (Home Manager) — no root entry point, imported only by each platform's home gate
│   ├── core/
│   │   ├── base/           # the base: fonts · i18n(fcitx5) · portal (wm-policy driven) · XDG
│   │   │                   #   · nix (the user-domain nix plane, R30: caps.system-nix gated — native HM
│   │   │                   #     nix.settings/registry renders ~/.config/nix/nix.conf +
│   │   │                   #     registry.json, fleet identity consumed by value; rendered only in the standalone
│   │   │                   #     form of platforms without a system nix — the precedence chain forbids double-plane shadowing)
│   │   │                   #   · wsl (the caps.wsl-gated WSL userspace interop: wslview/WSLENV, T7.1)
│   │   ├── exp/            # extended features (optional modules)
│   │   │   ├── app/        # GUI applications (app-set heavyweight routing, T5.10:
│   │   │   │               #   full = the whole tree / lean = docs · reading · reverse-engineering / none = the trio set):
│   │   │   │               #   16 categories: browser · dl · editor · fm · game · im · image · misc
│   │   │   │               #   · model · music · note · office · re · reader · terminal · video
│   │   │   └── sys/        # system tools (the always-on layer, off the app-set heavyweight axis):
│   │   │       ├── ai/         #   AI CLI: claude-code · opencode · gemini-cli · kiro-cli
│   │   │       │               #   · cursor-cli · pi-coding-agent
│   │   │       ├── base/       #   base CLI: git · fzf · bat · eza · fd · ripgrep · yazi
│   │   │       │               #   atuin · starship · direnv · tmux · rbw · just · jq · yq
│   │   │       │               #   wl-clipboard · cliphist · wl-clip-persist · tealdeer · curl · wget
│   │   │       ├── compat/     #   compat: appimage-run
│   │   │       ├── fs/         #   filesystem: compress(zip/p7zip/zstd) · duf
│   │   │       ├── media/      #   media: ffmpeg · mpv
│   │   │       ├── misc/       #   misc: cava · cursor(pointer theme)
│   │   │       ├── monitor/    #   monitoring: btop · htop · bottom
│   │   │       └── shell/      #   Shell: zsh(fzf-tab+atuin) · fish(fzf-fish+autopair)
│   │   ├── sec/            # user security (the extension point; the system side lives at platform/nixos/system/core/sec)
│   │   └── srv/            # user services:
│   │       ├── cache/      #   cache: cachix
│   │       ├── db/         #   database client tools
│   │       ├── notify/     #   notifications: mako
│   │       └── security/   #   security: gnupg keyring
│   ├── wm/
│   │   ├── hyprland/       # Wayland WM (primary): hyprland + orc wallust injection + the full theme stack
│   │   │   └── theme/      # quickshell · rofi · swaync · satty · swayosd · wallust · waybar · wlogout · qtct
│   │   ├── niri/           # Wayland WM (alternative): niri + the theme stack
│   │   │   └── theme/      # satty · swaylock · swaync · swayosd · waybar · wlogout
│   │   └── none/           # Null-Object: the empty module (its existence upholds the home gate's unconditional import)
│   └── env/
│       ├── base/           # global base packages: clang · cmake · rustc · cargo · python314 · nodejs_26
│       │                   # debugging tools: valgrind · strace · ltrace · pciutils · vulkan-tools
│       └── dev/            # pdshell devShell definitions (one directory per language, not an HM module tree)
│           ├── asm · c · cpp · go · java · javascript · typescript
│           ├── lisp · lua · nix · python · re · rust · zig
│           └── default.nix # composite environments: default(all languages) · cpython · godot · makeOs · rs_compiler_dev
│
├── hosts/                 # multi-host support (per-machine facts + policy overrides)
│   ├── nixos/             # the default host: hardware.nix (legacy-generated) + default.nix (the NVIDIA fingerprint)
│   │                      #   + deploy.nix (colmena deployment facts, T20.1 — file existence is itself the declaration)
│   ├── vm/                # evaluation-grade VM host: facter.json + disk.nix + persist.nix (declarative
│   │                      #   hardware/disk/state facts, T5.12/T5.13/T5.14)
│   │                      #   + shared.nix policy override (ephemeral root: / is wiped by rollback at every boot,
│   │                      #   /persistent · /nix · /boot survive as sibling subvolumes)
│   ├── wsl/               # WSL host: shared.nix (the platform=wsl class flip, no system fact files)
│   ├── nixos-wsl/         # NixOS-WSL host (T7.1): shared.nix (the platform=nixos-wsl
│   │                      #   fifth-row flip + dm/wm none + the lean set) + default.nix (the only machine
│   │                      #   fact = arch — no facter/disk/persist, see the file header)
│   └── darwin/            # darwin host: shared.nix (platform=darwin + aarch64-darwin)
│                          #   + default.nix (the eval-level host entry; activation awaits a real machine)
│
├── secrets/
│   ├── chipr/              # SOPS-encrypted files (committed to Git; .sops.yaml governs decryption rights)
│   └── plan/               # plaintext template instances (⚠️ never commit to Git — already excluded by .gitignore)
│
├── export/
│   ├── nixos/              # reusable NixOS modules (the flake output nixosModules: portal · fcitx5)
│   └── home/               # reusable Home Manager modules (homeModules: fcitx5 · shell · waybar · yazi)
│
├── overlays/               # nixpkgs overlay: additions(pkgs/) · patches
├── pkgs/                   # custom derivations (wslview — the minimal shim after wslu was archived)
│
├── tests/                  # the test layer (6 planes, 103 tests + 6 repo-hygiene checks = 109 checks)
│   ├── default.nix         # the unified registry: all Plane 0–5 checks (nixosTest runner)
│   ├── test_calc.nix       # Plane 0: the smoke baseline
│   ├── nixos/              # Plane 1: NixOS-Plane (QEMU VM, 30 tests)
│   ├── home/               # Plane 2: HM-Plane (QEMU VM + packages, 42 tests)
│   ├── lib/                # Plane 3: Lib-Plane (pure Nix eval, QEMU 256 MB minimal, 13 tests)
│   ├── integration/        # Plane 4: Integration-Plane (NixOS + HM combined, 1 test)
│   ├── fixtures/           # eval-time secret-existence fixtures (pathExists probes)
│   └── nmt/                # Plane 5: nmt-Plane (zero VM, pure eval, 16 tests)
│       ├── default.nix     # buildHomeManagerTest implementation + the registry (with the package-scrubbing whitelist)
│       └── home/           # test files (lib.nmt.buildHomeManagerTest)
│
├── scripts/
│   ├── just/               # justfile submodules (single-responsibility layering)
│   │   ├── shared.just     # shared.nix generation (tmpl → generate → overwrite)
│   │   ├── hardware.just   # hardware-fact generation (facter declarative / generate legacy)
│   │   ├── disk.just       # disko disk layout + state policy (disk-show/persist-show eval acceptance / disk-format application)
│   │   ├── flake.just      # flake inputs dependency management (update subset policy + lock inspection)
│   │   ├── deploy.just     # the three host-closure activation channels (nixos-rebuild / home-switch / colmena deploy)
│   │   ├── devenv.just     # dev-environment profile management (pdshell; the shell inventory = the flake devShells SSOT)
│   │   ├── services.just   # on-demand service management (systemctl verb wrappers + db-axis IR inspection)
│   │   ├── secrets.just    # Age keys + the SOPS encryption lifecycle (dual-domain key hierarchy + registry-driven)
│   │   ├── cachix.just     # the public binary-cache axis (status probing / token registration / local push)
│   │   ├── commit.just     # data-driven commit-convention deployment (built on the commit-config flake input)
│   │   └── dump.just       # project text export (for docs / auditing)
│   └── sh/                 # utilities (the path_headers @path header guard · the single source of the
│                           #   test count · the secrets-rotate runbook · the dump pipeline ·
│                           #   the secrets-db registry engine: CRUD + sqlite cache)
│
├── docs/
│   ├── architecture/       # deep architecture: mechanisms.md (the eleven-layer mechanisms) · tree.md (this file)
│   │                       #   · pipeline.md (compiler pipeline & layering full reference:
│   │                       #     pass cards · layer×stage bridge · cross-cutting dimensions · invariants · playbooks)
│   │                       #   · comparison.md (peer comparison & 16-dimension scoring, a dated snapshot)
│   │                       #   · dependency-graph.md (moved out during the T13.1 layered refactor)
│   ├── ci/                 # pipeline.md (the CI/CD deep manual: pre-flight / deployment / generations / automation)
│   ├── guides/             # quickstart.md (the full six-Phase run) · extending.md (the extension guide)
│   │                       #   · sound-adjudication.md (the debt #9 semantic-half adjudication dossier, T17.1)
│   ├── just/               # reference.md (the full 98 recipes × 14 groups reference)
│   ├── preview/            # screenshot previews
│   ├── modules/            # interface specification for export/ modules (interface-standards.md)
│   ├── secrets/            # rotation.md (the rotation runbook) · scenarios.md (the nine-scenario manual)
│   ├── tests/              # test documentation: test-matrix.md · nixosTest.md · nmt.md
│   └── tmpl/
│       ├── shared.nix.tmpl # the policy-layer template (__USERNAME__ placeholder; committed to Git)
│       └── sops/           # SOPS secret YAML templates (mirroring the path hierarchy)
│           ├── sops-rules.yaml.tmpl
│           └── nixos/      # template YAML files (__USERNAME__ / __SECRET_VALUE__ placeholders)
│
├── .github/
│   └── workflows/
│       ├── ci.yml          # 10-stage CI pipeline (lint → deep-eval → nmt → devshells
│       │                   #   → output-faces → security → vm-tests →
│       │                   #   host-toplevels → darwin-toplevels → summary)
│       ├── cache-attic.yml # opt-in self-hosted cache push (vars/secret gated; skipped when unset)
│       └── update-flake.yml# auto-update the flake inputs every Sunday and open a PR
│
└── justfile                # the task-automation entry point (ROOT variable + submodule imports + the bare-just map)
```
